## About

A single-page personal site covering what I build and write about, selected
projects (including Cuurios), open-source work, and my background.

## Built with

- Static HTML, CSS, and JavaScript — no framework, no build step
- Designed and generated with [Claude Design](https://claude.ai/design)
- Hosted on [Cloudflare Pages](https://pages.cloudflare.com), auto-deployed on every push to `main`

## Run locally

It's a static site, so you can open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Updating the site

Re-export from Claude Design, replace the files, and push to `main`.
Cloudflare Pages builds and deploys the new version automatically.
